# hafiz-kilo

The [Kilo](https://kilo.ai) plugin for [Hafiz](https://github.com/mewais/Hafiz#readme): role
agents, Hafiz tools, context shaping for the project block tree, and a TUI panel.

```sh
npm i -g hafiz-context-manager   # the `hafiz` CLI this plugin drives
hafiz install kilo               # adds hafiz-kilo to Kilo's plugin list (--project for this repo only)
```

Restart Kilo to load it. `hafiz uninstall kilo` removes it; `hafiz doctor` checks the wiring.

Full documentation: https://github.com/mewais/Hafiz#readme
